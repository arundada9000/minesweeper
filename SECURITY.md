# Security Policy

## Reporting a vulnerability

Please report security issues privately instead of opening a public issue.
Contact the owner through the repository's owner account:

https://github.com/arundada9000

Include:

- A short description of the issue and its impact.
- Steps to reproduce.
- The affected version or commit, if known.

You can expect an acknowledgment within a few days. Please do not disclose the
issue publicly until it has been addressed.

## Scope

SweeperMine is a fully client-side static application. In scope: persistence
(`localStorage`) handling, service worker caching behavior, and anything that
affects other users or sites (should not exist, by construction). Out of scope:
generic browser or operating-system vulnerabilities.

## Responsible disclosure

If you follow this policy, we will not pursue legal action against you for
researching and reporting the issue.
