# Changelog

All notable changes to SweeperMine are tracked here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases
semantic-version to the plan in `rules/plan.md`.

## [Unreleased]

## [0.1.0 Stage 8] - 2026-09-13

### Added

- PWA shell: manifest, offline-first service worker, install prompt, app icons,
  favicon, and social card (`og.png`), all generated by `scripts/make-icons.mjs`.
- SEO/AEO metadata: Open Graph, Twitter card, robots, sitemap, structured data
  (WebApplication JSON-LD), and a canonical URL in `src/lib/site.ts`.
- Custom 404 and root error pages themed to the app.
- Console easter egg and footer watermark crediting Arun Neupane.
- Custom-board toggles: first-click safety and question marks (game-logic §48).
- Pan and pinch zoom for large boards, with gesture-safe taps (game-logic §45).

### Changed

- Sound engine split into master / gameplay / UI gain stages with volume
  sliders (game-logic §42).
- Viewport locked to `user-scalable=no` so page-level pinch cannot fight the
  board's own zoom gesture.

### Fixed

- Solver-backed hints now gate the time record and are fully serialized
  (game-logic §30).

## [0.1.0 Stage 7] - HUD, modes, onboarding

- Live flag counter, centered board, practice mode, first-run onboarding.

## [0.1.0 Stage 5-6] - Engine + classic shell

- Rule-first minesweeper engine: board generation, first-click safety, flag
  cycle (configurable question marks), chord, undo, save/resume.
- Classic mode with gestures, keyboard play, HUD, timer, overlays, mode picker,
  settings, and continue flow.

## [0.1.0 - before] - Project scaffolding

- Next.js static-export app bootstrap, rule book in `rules/`, token system.
